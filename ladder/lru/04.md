# 4 · Is the cache any good? Count it

**The idea.** A cache that is never hit is a slower dictionary. Real
systems measure: a *hit* is a `get` that found the key, a *miss* one that
didn't, an *eviction* a key thrown out to make room. Counters live on the
object and a method reports them as a dictionary:

```python
class Door:
    def __init__(self):
        self.opened = 0
        self.locked_out = 0

    def report(self):
        return {"opened": self.opened, "locked_out": self.locked_out}
```

`self.opened += 1` is short for `self.opened = self.opened + 1`.
