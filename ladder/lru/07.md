# 7 · Tell me when you throw something away

**The idea.** A cache in front of a database often must *write back* what
it evicts. The caller hands you a function to call, like the clock in unit
1 stage 8. `None` as the default means "nobody asked":

```python
class Alarm:
    def __init__(self, on_ring=None):
        self.on_ring = on_ring

    def ring(self, time):
        if self.on_ring is not None:
            self.on_ring(time)          # call whatever they gave us

heard = []
Alarm(on_ring=heard.append).ring("07:00")
print(heard)                            # ['07:00']
```
