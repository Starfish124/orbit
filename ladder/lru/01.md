# 1 · A cache is a store that forgets

**The idea.** A *cache* keeps a limited number of things close by. When it is
full and something new arrives, something old must go. Unit 1 gave you the
store; now it needs a memory of *order*. A list remembers order:

```python
queue = []
queue.append("ana")        # joins at the back
queue.append("bo")
first = queue.pop(0)       # takes from the FRONT: "ana"
print(first, queue, len(queue))   # ana ['bo'] 1
```

Guarding bad input is part of the job, as in unit 1:
`raise ValueError("capacity must be at least 1")`.
