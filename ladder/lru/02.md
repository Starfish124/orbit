# 2 · Least *recently used*

**The idea.** "First in, first out" throws away things you still use. An
LRU cache throws away the key **used longest ago**. Reading a key counts as
using it, so it moves to the back of the line:

```python
line = ["ana", "bo", "cy"]
line.remove("ana")         # take it out wherever it is
line.append("ana")         # and put it at the back
print(line)                # ['bo', 'cy', 'ana']
```

**Your turn.** Make `get` of an existing key mark it as most recently
used. The key thrown out is now always the least recently used one.

**Checked:** capacity 2: put a, put b, get a, put c → **b** is thrown out,
not a. A `get` of a missing key changes nothing.
