# 3 · Overwriting is using

**The idea.** Edge cases are where interviews are decided. What happens
when you `put` a key that is **already** in the cache? Three things must
hold, and it is easy to break one:
- the value is replaced
- the key becomes most recently used
- nothing is evicted, because no new key arrived

A common bug: the key ends up in your order list **twice**. Then `size()`
and eviction quietly go wrong later. Print your order list and look.

**Your turn.** Make `put` of an existing key follow all three rules.

**Checked:** capacity 2: put a, put b, put a again, put c → b is thrown
out; size stays honest through many overwrites.
