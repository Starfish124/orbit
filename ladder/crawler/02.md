# 2 · How far from home

**The idea.** Real crawlers stop at some distance: "no more than 2 clicks
from the home page". To know how far a page is, keep the distance *next to*
it in the queue. A **tuple** holds a few values together, and you can
unpack it straight into names:

```python
from collections import deque

jobs = deque([("print", 1), ("scan", 3)])
name, tries = jobs.popleft()       # unpacking: name="print", tries=1
jobs.append((name, tries + 1))     # back in, one more try
print(list(jobs))                  # [('scan', 3), ('print', 2)]
```

Why BFS and not "go deep first" (DFS)? A queue visits everything 1 click
away, then everything 2 clicks away, and so on. So the first time BFS sees
a page, it has found the **shortest** way there. Going deep first can reach
a page the long way round, call it "too far", and never look again.

`None` means "no limit". Test for it with `is None`, because `0` is a real
limit and `if not max_depth` would treat it as "no limit".

**Your turn.** `crawl(start, fetch, max_depth=None)`:
- `start` is depth 0, pages it links to are depth 1, and so on
- keep pages up to `max_depth`; pages exactly at `max_depth` are in the
  result but are **not fetched** (their links would be too far)
- with no `max_depth`, crawl everything, as before
- fetch pages level by level, in the order the links appear

**Checked:** fetch order is level by level; `max_depth=2` keeps a page
that is 1 click away even when a longer path reaches it first;
`max_depth=0` fetches nothing.
