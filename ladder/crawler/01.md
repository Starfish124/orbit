# 1 · Follow every link, once

**The idea.** A website is a *graph*: pages are the dots, links are the
arrows. A crawler starts on one page and keeps following arrows until it
has seen everything it can reach. Two tools do the work:

- a **queue** of pages still to visit. `collections.deque` is a list built
  for this: `popleft()` takes from the front in O(1) (unit 2 showed why
  `list.pop(0)` is O(n))
- a **set** of pages already seen. `x in some_set` is O(1), and a set
  never holds anything twice

```python
from collections import deque

todo = deque(["wash", "dry"])
todo.append("fold")            # joins at the back
print(todo.popleft())          # wash, from the front

done = {"wash"}
done.add("dry"); done.add("dry")
print("dry" in done, len(done))   # True 2
```

Links go in circles (`/a` links to `/b`, `/b` links back to `/a`). Without
the seen set, a crawler walks that circle forever. So the rule is: add a
page to `seen` **the moment you discover it**, not when you visit it.
Visiting in queue order like this is called **BFS** (breadth-first search).

There is no internet here. Someone hands you a function, `fetch`, and
`fetch(url)` returns the list of links on that page. You only call it.
