# 3 · Links are messy

**The idea.** Real pages don't link with full URLs. They write `about`,
`/faq#top`, `../contact`, `#section2`, or point at other websites. A
crawler must turn every link into one clean, full URL, or it fetches the
same page under three names. Python ships the parts in `urllib.parse`:

```python
from urllib.parse import urldefrag, urljoin, urlparse

page = "http://shop.nl/shoes/red"
print(urljoin(page, "blue"))        # http://shop.nl/shoes/blue
print(urljoin(page, "/cart"))       # http://shop.nl/cart
print(urljoin(page, "../hats/"))    # http://shop.nl/hats/
print(urldefrag("http://shop.nl/cart#pay").url)   # http://shop.nl/cart
print(urlparse("http://shop.nl/cart").netloc)     # shop.nl
```

`urljoin` resolves a link *relative to the page it was found on*, exactly
like a browser. The part after `#` (the *fragment*) only scrolls the page;
it is the same page, so drop it. `netloc` is the host: compare it to stay on
one site.
