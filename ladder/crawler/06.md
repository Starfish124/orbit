# 6 · Waiting without threads (asyncio)

**The idea.** Threads are one way to overlap waiting. **asyncio** is
another: one thread, many tasks, and each task says *where* it waits.

- `async def` makes a *coroutine* function. Calling it doesn't run it yet;
  it gives you something to `await`
- `await x` means "pause me here until x is ready; run others meanwhile"
- `asyncio.gather(a, b, c)` runs several at once and returns their results
  as a list, in the order you passed them
- `asyncio.run(main())` starts the whole thing from normal code

```python
import asyncio

async def brew(drink, seconds):
    await asyncio.sleep(seconds)      # never time.sleep here: it blocks everyone
    return drink

async def main():
    cups = await asyncio.gather(brew("tea", 0.2), brew("coffee", 0.1))
    print(cups)                       # ['tea', 'coffee'] after ~0.2 s

asyncio.run(main())
```

The `*` in `gather(*coros)` spreads a list into separate arguments. And no
lock is needed here: only one task runs at a time, and it only switches at
an `await`.
