# 7 · Don't hammer the server (Semaphore)

**The idea.** `gather` over 1000 links fires 1000 requests at once. The
site slows down or blocks you. A polite crawler caps how many requests are
in flight. `asyncio.Semaphore(n)` is a counter of free slots: `async with`
takes a slot (waiting if none is free) and gives it back at the end of the
block, even if an error happened inside.

```python
import asyncio

lift = asyncio.Semaphore(3)            # room for 3 people

async def ride(person):
    async with lift:                   # wait here until there is room
        await asyncio.sleep(0.1)       # at most 3 are ever inside this block
    return person

async def main():
    print(await asyncio.gather(*[ride(p) for p in "abcdefg"]))

asyncio.run(main())                    # ~0.3 s: 3 + 3 + 1
```

You still `gather` everything; the semaphore makes the extras wait their
turn. Create it **inside** the async function (a semaphore belongs to the
event loop that `asyncio.run` starts).

**Your turn.** `crawl_async(start, fetch, limit=None)`:
- never more than `limit` fetches running at the same time
- `limit=None` means no cap, as before

**Checked:** 20 pages with `limit=3`: never more than 3 at once, but
really 3 (not one by one); `limit=1` means strictly one at a time.
