# 4 · Sorting with a key

**The idea.** `sorted(things)` sorts by the things themselves. To sort by
something *about* them, pass `key=`: a function that turns each item into
the value to compare. A `lambda` is a one-line function, perfect here.

Sorting by two rules at once? Make the key a **tuple**. Tuples compare
item by item: `(3, "b") < (3, "c")` because the first items tie and `"b"`
comes first. To sort one part high-to-low, negate it: `-score`.

Example: a leaderboard, most points first, ties by name A-Z:

```python
points = {"zoe": 40, "adam": 55, "mia": 40}
rows = sorted(points.items(), key=lambda item: (-item[1], item[0]))
print(rows)                   # [('adam', 55), ('mia', 40), ('zoe', 40)]
print(rows[:2])               # slicing: just the first two
print([f"{name}:{p}" for name, p in rows])   # ['adam:55', 'mia:40', 'zoe:40']
```

`dict.items()` gives `(key, value)` pairs. The `f"..."` is an **f-string**:
anything inside `{}` is filled in.
