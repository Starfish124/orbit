# 3 · Measure closeness and keep the best k

**The idea.** Two vectors point in similar directions when they share
heavily weighted words. **Cosine similarity** measures the angle, ignoring
length:

    cosine(a, b) = dot(a, b) / (|a| * |b|)
    dot(a, b)    = sum of a[w] * b[w] over words w in both
    |a|          = sqrt(sum of a[w] ** 2 over all w in a)

It is 1.0 for the same direction, 0.0 for no shared words. An empty vector
has length 0: return `0.0` instead of dividing by zero.

Then **top-k**: sort `(id, score)` pairs best first. Ties must be broken the
same way every run, or tests and users see results jump around.
`sorted(items, key=...)` sorts by whatever the key function returns; a
tuple key sorts by its first part, then the second. `lambda p: ...` is a
tiny unnamed function. Different job, runners by time then name:

```python
runs = [("zoe", 31.5), ("al", 29.0), ("bo", 31.5)]
fastest = sorted(runs, key=lambda p: (p[1], p[0]))
print(fastest)    # [('al', 29.0), ('bo', 31.5), ('zoe', 31.5)]
```

To sort *highest* first, sort by the negative: `-p[1]`.
