# 6 · Build the prompt, call the model, or admit you don't know

**The idea.** Retrieval gives ranked chunks; now build the prompt. Number
the sources so the model can cite `[1]`, and keep under a size **budget**
(real models have a context limit and charge per token; here the budget is
counted in characters). When it doesn't fit, drop the *lowest-ranked*
source first: it's the least likely to matter.

The model is **injected**: `answer` takes an `llm` function (prompt in,
text out). Tests pass a fake; production passes a real API call. Same trick
as the injected clock in unit 1.

The most important path is the one that doesn't call the model: if the best
chunk scores below `min_score`, retrieval found nothing good, and a model
given junk will confidently make things up. Return "I don't know" instead.
(A BM25 score has no absolute meaning: 1.0 is a knob you tune on your
own data with the eval from stage 7, never a universal constant.)

Different job, a packing list under a weight limit, dropping the least
important item until it fits:

```python
items = [("tent", 3), ("stove", 2), ("book", 1)]    # most important first
while items and sum(w for _, w in items) > 5:
    items.pop()                                      # drop the last one
print(items)    # [('tent', 3), ('stove', 2)]
```

**Your turn.**
- `build_prompt(question, passages, budget)`: `passages` is a ranked list of
  `(chunk_id, text)`. The prompt is exactly the header
  `"Answer the question using only the sources below. Cite them like [1].\n\n"`,
  then per passage `"[n] chunk_id\ntext\n\n"` (n from 1), then
  `"Question: " + question + "\nAnswer:"`. Drop passages from the end until
  `len(prompt) <= budget`. Return `(prompt, used_ids)`. If even zero
  passages don't fit: `ValueError`.
- `Index.answer(question, llm, k=3, min_score=1.0, budget=1500)`: search;
  no hits or best score `< min_score` returns
  `{"answer": "I don't know", "sources": []}` **without calling `llm`**;
  otherwise `{"answer": llm(prompt), "sources": used_ids}`.

**Checked:** the exact prompt text, budget drops the last source, the model
is called once with that prompt, and a fake that raises proves it is never
called when retrieval fails.
