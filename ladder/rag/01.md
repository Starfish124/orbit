# 1 · Cut documents into overlapping chunks

**The idea.** This unit builds **RAG**, retrieval-augmented generation: before
asking a language model a question, you *find* the few passages in your own
documents that matter and paste them into the prompt. No framework, every
part by hand. The LLM itself arrives later as a plain function you are given.

Step one: a document is too long to paste whole, so you cut it into
**chunks** of `size` words. Neighbouring chunks share `overlap` words, so a
sentence cut at a border still appears whole in one of them. Each chunk
starts `size - overlap` words after the previous one (the *step*).

`text.split()` with no argument splits on any run of spaces, tabs or
newlines and never gives empty strings. `" ".join(words)` glues a list back
with single spaces. Slicing past the end is safe: `[1, 2][1:10]` is `[2]`.

Same shape, different job: a sliding window of 3 days over temperatures.

```python
temps = [20, 22, 19, 25, 24]
step = 2
start = 0
while start < len(temps):
    print(temps[start:start + 3])      # [20, 22, 19] then [19, 25, 24]
    if start + 3 >= len(temps):        # this window reached the end: done
        break
    start = start + step
```

**Your turn.** New file, `rag.py`.
`chunk(doc_id, text, size, overlap)` returns a list of `(chunk_id, chunk_text)`
tuples:
- words = `text.split()`; chunk `i` is the words from `i * (size - overlap)`
  up to `size` words, joined with one space
- stop after the first chunk that reaches the last word (the last chunk may
  be shorter); no words at all gives `[]`
- `chunk_id` is `doc_id + "#" + i`, counting from 0: `"doc#0"`, `"doc#1"`...
- `size < 1`, `overlap < 0` or `overlap >= size`: `raise ValueError(...)`

**Checked:** 10 words with size 4, overlap 1 give `w0-w3`, `w3-w6`, `w6-w9`;
11 words add a short `"w9 w10"`; whitespace is normalised; bad sizes raise.
