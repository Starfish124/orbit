# 2 · Turn text into weighted words (TF-IDF)

**The idea.** To compare a question with a chunk, turn both into numbers.
First **tokenize**: lowercase, and treat everything that is not a letter or
digit as a break. `ch.isalnum()` is `True` for letters (including `é`) and
digits. Then weigh each word:

- **tf** (term frequency): how often the word is in this text
- **idf** (inverse document frequency): how *rare* the word is across all
  chunks. "the" is everywhere and tells you nothing; "boiler" is rare and
  tells you a lot. With `N` docs and `df` = the number of docs containing
  the word (a doc counts once, however often it repeats the word):

      idf = ln((N + 1) / (df + 1)) + 1        # math.log is ln

- weight = `tf * idf`

A vector is a **dict** `{word: weight}` holding only the words present
(a *sparse* vector: absent means 0). `set(tokens)` gives each word once.

Counting with a dict, on a different job (votes):

```python
votes = ["yes", "no", "yes"]
tally = {}
for v in votes:
    tally[v] = tally.get(v, 0) + 1     # .get gives 0 the first time
print(tally)                           # {'yes': 2, 'no': 1}
```
