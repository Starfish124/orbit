# 5 · Reading what the model wrote

**The idea.** Real models return **text**, not dicts. You asked for JSON,
but you get `Sure! {"tool": ...}` or JSON inside ``` fences, and sometimes
broken JSON. Your agent has to dig the object out and, when it can't,
tell the model and let it try again.

Tools for the dig, on a different mess:

```python
import json

page = 'Stock report: {"apples": 3, "pears": {"ripe": 1}} -- end'
start = page.find("{")           # first {, or -1 if none
end = page.rfind("}")            # LAST }, so nested {...} stay inside
data = json.loads(page[start:end + 1])
print(data["pears"]["ripe"])     # 1

json.loads("{apples: 3}")        # raises JSONDecodeError, a kind of ValueError
isinstance("hi", str)            # True: is this value a string?
raise ValueError("no stock data")  # how YOU signal "bad input"
```
