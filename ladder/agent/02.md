# 2 · Never trust the caller

**The idea.** The model asks for a tool by name, with arguments in a dict
like `{"a": 2, "b": 3}`. `**` unpacks a dict into named arguments:

```python
def greet(name, mark="!"):
    return "hi " + name + mark

opts = {"name": "Ana", "mark": "?"}
print(greet(**opts))             # same as greet(name="Ana", mark="?")
```

Models get things wrong all the time: a tool that doesn't exist, a
missing argument, an argument that makes the tool crash. If your agent
crashes, the whole job is gone. Instead, catch the problem and turn it into
**text the model can read**, so it can try again:

```python
try:
    n = int("abc")
except Exception as e:           # any error lands here, the program lives on
    print(type(e).__name__, e)   # ValueError invalid literal for int()...
```

**Your turn.** `call_tool(name, args)` returns a **string**, always:
- runs the tool with `args` and returns the result as text (`str(...)`),
  so `call_tool("add", {"a": 2, "b": 3})` is `"5"`
- unknown tool: a string starting `error:` that names the tool
- wrong arguments, args that aren't a dict, or the tool raising: a string
  starting `error:` that includes the exception's message

**Checked:** `"5"` and `"HI"`; five broken calls each give an `error:`
string (with the tool name / `division by zero` where useful), never a crash.
