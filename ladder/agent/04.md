# 4 · The model that never stops

**The idea.** Real models get stuck: they call the same tool again and
again, never saying `final`. Your `while True` would run forever (and
spend money forever). Every agent has a **step limit**. A `for` loop over
`range` gives you one for free, and whatever comes after the loop runs
only when the limit was reached:

```python
def guess_code(try_code, max_tries=3):
    for attempt in range(max_tries):
        if try_code(attempt):
            return "opened on try " + str(attempt + 1)
    return "locked: gave up after " + str(max_tries) + " tries"
```

Returning a clear message beats raising here: the caller gets a string it
can show, and knows *why* there is no answer.

**Your turn.** `run(task, model, max_steps=10)`:
- a step is one call to `model`; call it at most `max_steps` times
- no `final` by then: return a string starting `stopped:` that says the
  limit, e.g. `"stopped: no final answer after 5 steps"`
- a `final` on the very last allowed step still counts

**Checked:** a model that loops forever is called exactly 5 times (10 by
default) and you get `stopped:` with the number; a final on step 3 of 3 wins.
