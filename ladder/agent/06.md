# 6 · The flight recorder

**The idea.** When an agent does something odd, the first question is
*"what did it do, step by step?"* So every step is written down. The
second question is *"what did it cost?"* Models bill per **token** (roughly
a word), and remember: every call sends the **whole** history again, so
call 10 pays for everything from calls 1..9 once more.

Time and counting are injected, like the clock in unit 1, so tests can
use fake ones:

```python
import time

def bake_all(cakes, clock=time.monotonic):
    log = []
    for cake in cakes:
        start = clock()
        # ... bake ...
        log.append({"cake": cake, "seconds": clock() - start})
    return log
```

A module-level dict can hold "the last run" for anyone to inspect. Change
what is *inside* it (`last_run["trace"] = []`) and no `global` is needed.

**Your turn.** `run(..., clock=time.monotonic, count_tokens=<counts words>)`
and a module-level dict `last_run`, reset at the start of every run:
- `last_run["trace"]`: one dict per model call with `step` (1, 2, ...),
  `tool` and `args` (`None` when it wasn't a tool call), `result` (tool
  result, final answer, or the `error:` text), `seconds` (from just before
  the model call to after the tool finished), `tokens` (below)
- `tokens` for a call = `count_tokens(content)` summed over every message
  sent in that call; `last_run["tokens"]` = the total over all calls
