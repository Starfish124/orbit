# 7 · Ask a human first

**The idea.** Some tools can't be undone: deleting files, sending email,
paying money. A model that misreads the task shouldn't be able to do
those alone. **Human in the loop**: the agent asks a person first, and a
"no" goes back to the model as text, so it can find another way.

Same shape as the callbacks from unit 2: the caller passes a function,
you call it at the right moment. And the safe default: nobody to ask means
the answer is no.

```python
def transfer(amount, confirm=None):
    if amount > 100:
        if confirm is None or not confirm(amount):
            return "refused: needs a yes for " + str(amount)
    return "sent " + str(amount)

print(transfer(500, confirm=lambda amount: False))   # refused: ...
```

(`lambda args: expression` is a one-line function without a name.)
