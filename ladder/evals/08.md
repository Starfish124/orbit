# 8 · The loop: report and baseline

**The idea.** An eval only changes behaviour if it runs every time and
someone reads it. Two pieces close the loop:

- a **baseline**: the last accepted run, saved to a file. Every new run is
  compared against it automatically. Only accept a new baseline when
  nothing regressed; otherwise one bad release quietly becomes the new
  normal.
- a **report** a human reads in ten seconds: the total, what broke, where
  it is weakest.

`json.dump(obj, f)` writes a dict into an open file; `json.load(f)` reads
it back. `os.path.exists(path)` checks for a file first.

```python
import json, os

if os.path.exists("settings.json"):
    with open("settings.json") as f:
        settings = json.load(f)
else:
    settings = {"volume": 5}
with open("settings.json", "w") as f:
    json.dump(settings, f)
```

`"%+.1f" % 2.5` gives `+2.5` (always a sign); `"%.1f%%" % 62.5` gives `62.5%`.

- `save_baseline(run_result, path)`; `load_baseline(path)` → the dict, or
  `None` when the file doesn't exist
- `report(run_result, baseline=None)` → markdown text, lines in this order:
  `# Eval report`, then `pass rate: 62.5% (5/8)`, then either
  `no baseline`, or `change: +12.5 points` (points = percent),
  `significant: yes (p=0.0020)` / `significant: no (p=1.0000)`,
  `## Regressions` and `## Improvements` with one `- id` line each (`- none`
  if empty); last `## Worst slices`: up to 3, as `- geo: 0.0% (0/3)`
- `evaluate(cases, system, grader, baseline_path)` → `(run_result, text)`:
  runs, reports against the saved baseline, and saves this run as the
  baseline when there was none or it has **no regressions**
