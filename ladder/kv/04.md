# 4 · Loops: look at everything

**The idea.** A `for` loop runs its body once per item. Looping over a
dictionary gives you its keys; `.items()` gives you key and value together.

```python
ages = {"ana": 31, "bo": 25, "cy": 31}
total = 0
for name in ages:                    # name = "ana", then "bo", then "cy"
    total = total + 1

same = []                            # an empty list
for name, age in ages.items():
    if age == 31:
        same.append(name)            # add to the end of the list
print(sorted(same))                  # ['ana', 'cy']
```

`==` compares, `=` assigns. Mixing them up is the most common beginner bug.
