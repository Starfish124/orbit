# 7 · Transactions inside transactions

**The idea.** New requirement: `begin()` may be called while a transaction
is already open. Each `rollback` or `commit` closes only the **innermost**
one. Rolling back an outer transaction also undoes inner ones that were
committed, because they were inside it.

One snapshot slot can't hold that. You need a *stack*: a list where the
last thing added is the first thing taken off.

```python
plates = []
plates.append("red")       # push
plates.append("blue")
top = plates.pop()         # pop: takes "blue", the last one in
print(top, plates)         # blue ['red']
if not plates:             # an empty list counts as False
    print("no plates")
```

**Your turn.** Make `begin`/`rollback`/`commit` nest:
- each `begin` pushes a snapshot
- `rollback` restores the innermost snapshot and pops it
- `commit` pops the innermost snapshot and keeps the data as it is
- still `RuntimeError` when nothing is open

**Checked:** inner rollback keeps outer changes; inner commit then outer
rollback undoes both; counts of open transactions stay honest.
