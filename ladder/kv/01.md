# 1 · A dictionary is already a database

**The idea.** A *dictionary* stores values under *keys*. You write a value with
`box[key] = value` and read it back with `box[key]`. That is all a key-value
store is; everything in this unit grows out of these two moves.

Here is one on a different topic, a phone book:

```python
phones = {}                    # an empty dictionary
phones["mum"] = "06-1234"      # store: key "mum" -> value "06-1234"
phones["work"] = "020-555"
print(phones["mum"])           # read: prints 06-1234
```

`=` means "put the thing on the right into the name on the left". Text goes in
quotes; `"mum"` is text, `mum` without quotes would be a variable name.
