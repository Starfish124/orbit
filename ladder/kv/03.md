# 3 · What isn't there

**The idea.** Try `get("nope")` now: it crashes with a `KeyError`. In an
interview, the missing case is half the grade. Two tools handle it:

```python
if "mum" in phones:            # `in` asks: is this key there? True/False
    print("found")
else:
    print("no such contact")

def remove(name):
    if name not in phones:
        return False           # return early: the function stops here
    del phones[name]           # delete a key
    return True
```

`None` is Python's word for "nothing". A function that reaches its end
without a `return` hands back `None` on its own.

**Your turn.**
- `get(key)` returns `None` when the key is missing (no crash)
- new `delete(key)`: removes the key and returns `True`; returns `False`
  when there was nothing to delete

**Checked:** missing get is `None`; delete returns True, then False the second time.
