# 6 · Transactions: try something, then undo it

**The idea.** A *transaction* lets you make changes and then either keep
them (`commit`) or throw them all away (`rollback`). The simple way: at
`begin`, take a snapshot of the data; `rollback` puts the snapshot back.

The trap is *aliasing*. Assignment never copies:

```python
a = {"x": 1}
b = a              # b is the SAME dict, just a second name
b["x"] = 99
print(a["x"])      # 99 !
c = dict(a)        # this makes a real copy
```

Errors are also yours to raise. Code that is used wrong should say so:

```python
def withdraw(amount):
    if amount > balance:
        raise ValueError("not enough money")
```
