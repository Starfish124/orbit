# 2 · Functions: name the moves

**The idea.** A *function* is a named recipe. `def` defines it, the names in
brackets are its *parameters* (the ingredients it is handed), and `return`
hands a result back to whoever called it.

```python
scores = {}

def add_score(player, points):     # two parameters
    scores[player] = points        # indented = inside the function

def score_of(player):
    return scores[player]          # hand the value back

add_score("ana", 12)
print(score_of("ana"))             # 12
```

Indentation is not decoration in Python: the indented lines *are* the body.
Use 4 spaces (the editor does it for you after a `:`).
