# 3 · More ops, each with its own local slope

**The idea.** Every operation needs just two things: compute the output, and
know its *local slope* (how much the output moves when its input moves by
1). The chain rule does the rest: `self.grad += local_slope * out.grad`.

| op | output | local slope |
|---|---|---|
| `x ** n` (n a plain number) | `x.data ** n` | `n * x.data ** (n - 1)` |
| `x.exp()` | `math.exp(x.data)` | the output itself |
| `x.log()` | `math.log(x.data)` | `1 / x.data` |
| `x.tanh()` | `t = math.tanh(x.data)` | `1 - t * t` |

An op NOT in your task, `sin`, so you see the whole shape:

```python
import math

def sin(self):
    out = Value(math.sin(self.data), (self,))    # one child

    def _backward():
        self.grad += math.cos(self.data) * out.grad
    out._backward = _backward
    return out
```

Division needs no new rule: `a / b` is `a * b ** -1`.

How do you know your slope is right? **Check it against nudging**, your
stage 1 tool. Every autograd library tests itself this way (a *gradient
check*).
