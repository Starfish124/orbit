# 5 · From scores to probabilities (without overflowing)

**The idea.** A language model outputs one score (*logit*) per possible next
token. *Softmax* turns scores into probabilities: `exp` each, divide by
the total. They're all positive and sum to 1.

The loss for "the right answer was token t" is *cross-entropy*:
`-log(p[t])`. Right answer at probability 1 → loss 0; at 0.01 → loss 4.6.

**The trap.** `math.exp(1000)` is too big for a float: `OverflowError`.
The fix: subtracting the same number `m` from every score changes nothing
(`exp(a - m) / exp(b - m) = exp(a) / exp(b)`), so subtract the biggest and
the largest `exp` is `exp(0) = 1`. Same trick, plain floats, other job:
"a soft maximum" of a list, `log(sum(exp(x)))`:

```python
import math

def soft_max_value(xs):
    m = max(xs)
    return m + math.log(sum(math.exp(x - m) for x in xs))

print(soft_max_value([1000, 1001]))    # 1001.31..., no overflow
```

The same thing saves cross-entropy: when `p[t]` is so small it rounds to
0.0, `log(0)` crashes. Do the algebra first instead:
`-log(p[t]) = log(sum(exp(v - m))) - (v[t] - m)`: nothing ever gets tiny.

`m` should be a plain number (`max(v.data for v in logits)`): it shifts the
scores but no gradient needs to flow through it.
