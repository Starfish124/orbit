# 4 · Learning = walking downhill

**The idea.** A *model* is a function with knobs (*parameters*). A *loss*
is one number saying how wrong it is. `grad` tells you which way each knob
makes the loss go UP, so you nudge every knob the other way:
`p.data -= lr * p.grad`. Repeat. That is *gradient descent*; `lr` (learning
rate) is the step size.

One knob, plain floats: find the `w` where `(w - 3) ** 2` is smallest.

```python
w, lr = 0.0, 0.1
for step in range(50):
    grad = 2 * (w - 3)          # slope of (w - 3)**2
    w -= lr * grad
print(round(w, 3))              # 3.0
```

A `Linear` layer is the workhorse of every neural net: output `j` is
`b[j] + w[j][0]*x[0] + w[j][1]*x[1] + ...`. Its starting weights are random.
Randomness must be repeatable in tests, so the caller hands you a seeded
generator, like the injected clock in unit 1:

```python
import random
rng = random.Random(42)
print(rng.uniform(-1, 1))       # same number every run
```

Grads pile up (`+=`) across calls to `backward()`, so zero them every step.
