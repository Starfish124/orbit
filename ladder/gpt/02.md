# 2 · backward(): every slope in one sweep

**The idea.** Nudging works, but a GPT has thousands of inputs, and nudging
each one separately is far too slow. The trick behind all deep learning:
each Value remembers **which Values made it** and **how to pass a slope
back** to them. The *chain rule* says slopes multiply along the path:

- `out = a + b`: nudge `a` by 1, `out` moves by 1 → `a.grad += out.grad`
- `out = a * b`: nudge `a` by 1, `out` moves by `b` → `a.grad += b.data * out.grad`

Store the rule as a small function on `out` (a *closure*: it can see `a`,
`b` and `out` later). Use `+=`: a Value used twice gets slope from both uses.

The rules must run in the right order: a node only passes its slope back
after **everything that uses it** has passed slope to it. That order is a
*topological sort*. Same idea, other topic: getting dressed.

```python
needs = {"shoes": ["socks", "trousers"], "trousers": ["pants"],
         "socks": [], "pants": []}
order, seen = [], set()

def visit(item):
    if item not in seen:
        seen.add(item)
        for before in needs[item]:
            visit(before)            # do what it needs first
        order.append(item)

visit("shoes")
print(order)       # ['socks', 'pants', 'trousers', 'shoes']
```

For backward you walk that order **reversed**: output first.
