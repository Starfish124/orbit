# 1 · A number that remembers (and what a slope is)

**The idea.** This unit builds a tiny GPT in plain Python, the way Karpathy
does in *micrograd*. Everything rests on one question: **if I nudge this
input a little, how much does the output move?** That ratio is the
*derivative* (the slope). You can measure it by just trying:

```
slope of f at x  ≈  (f(x + h) - f(x)) / h      with h tiny, like 0.000001
```

A car's position is `pos(t) = 5 * t * t` metres. How fast is it going at t=2?

```python
def pos(t):
    return 5 * t * t

h = 0.000001
print((pos(2 + h) - pos(2)) / h)     # ~20.000005 metres per second
```

Second new thing: your own class can use `+` and `*`. Python turns `a + b`
into `a.__add__(b)` and `a * b` into `a.__mul__(b)`:

```python
class Money:
    def __init__(self, cents):
        self.cents = cents

    def __add__(self, other):
        return Money(self.cents + other.cents)   # a NEW object; a is untouched

print((Money(150) + Money(75)).cents)            # 225
```
