# 2 · Count the neighbours

**The idea.** BPE (byte pair encoding) finds the two numbers that sit next
to each other most often and glues them into one new number. Step one is
counting every *adjacent pair*. A pair is a **tuple**: `(104, 105)`. Tuples
can be dict keys; lists can't.

Walk the positions with `range(len(ids) - 1)` so `i + 1` never runs off the
end. `counts.get(key, 0)` means "the count so far, or 0 if new". Here is
the same idea counting which station follows which on a train line:

```python
stops = ["Ams", "Utr", "Ams", "Utr", "Den"]
hops = {}
for i in range(len(stops) - 1):
    hop = (stops[i], stops[i + 1])
    hops[hop] = hops.get(hop, 0) + 1
print(hops)   # {('Ams', 'Utr'): 2, ('Utr', 'Ams'): 1, ('Utr', 'Den'): 1}
```

Pairs overlap: `[5, 5, 5]` has `(5, 5)` at positions 0-1 **and** 1-2.

**Your turn.** `get_stats(ids)` returns a dict `{(a, b): count}` of every
adjacent pair in the list. It must not change the list it is given. Fewer
than two ids means no pairs: `{}`.

**Checked:** `[1, 2, 3, 1, 2]` gives `{(1, 2): 2, (2, 3): 1, (3, 1): 1}`,
