# 3 · Glue a pair into one id

**The idea.** Once you know a pair, you replace every place it appears with
a single new id. Walk left to right with a `while` loop and an index you
move yourself: jump **2** when you glued a pair, **1** otherwise. Build a
new list; don't edit the one you were given.

Same shape, different job: turning a backslash followed by `n` into a real newline.

```python
chars = ["a", "\\", "n", "b"]
out = []
i = 0
while i < len(chars):
    if i + 1 < len(chars) and chars[i] == "\\" and chars[i + 1] == "n":
        out.append("\n")
        i = i + 2              # used two, skip both
    else:
        out.append(chars[i])
        i = i + 1
print(out)   # ['a', '\n', 'b']
```

The `i + 1 < len(...)` check comes **first**: `and` stops as soon as it
sees `False`, so `chars[i + 1]` is never read past the end.

**Your turn.** `merge(ids, pair, new_id)` returns a new list where every
occurrence of `pair` (left to right, not overlapping) is replaced by
`new_id`.

**Checked:** `merge([1, 2, 3, 1, 2], (1, 2), 256)` is `[256, 3, 256]`;
`[5, 5, 5]` with `(5, 5)` gives `[256, 5]`; missing pairs change nothing;
the input list is untouched.
