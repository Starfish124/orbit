# 1 · Text is bytes underneath

**The idea.** A language model never sees letters. It sees a list of
numbers. The first step is turning a `str` into numbers. Python strings hold
*characters*; to store or send them, they are encoded as **bytes**, numbers
from 0 to 255. The standard encoding is **UTF-8**:

- plain English letters are 1 byte each (`"h"` is 104)
- `"é"` is 2 bytes, `"日"` is 3, an emoji like `"👋"` is 4

So the number of bytes is not the number of characters. `.encode("utf-8")`
turns a `str` into a `bytes` object. `list(...)` on that gives you the ints.
`bytes([...])` turns a list of ints back into `bytes`, and
`.decode("utf-8")` turns that back into a `str`.

```python
word = "naïve"
raw = word.encode("utf-8")      # b'na\xc3\xafve'  (ï became 2 bytes)
print(len(word), len(raw))      # 5 6
nums = list(raw)                # [110, 97, 195, 175, 118, 101]
print(bytes(nums).decode("utf-8"))   # naïve
```

**Your turn.** New file, `bpe.py`. This unit builds a **BPE tokenizer**, the
thing that turns text into the numbers GPT-style models read.
- `to_bytes(text)` returns the UTF-8 bytes of `text` as a **list** of ints
- `from_bytes(ids)` takes such a list and returns the `str`

**Checked:** `"hi"` is `[104, 105]`, `"é"` is `[195, 169]`, an emoji is 4
bytes, and a round trip gives the same text back for accents, Japanese and emoji.
